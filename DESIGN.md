# Turnstile visual direction

Use the shared Riso Poster system from the supplied design guide: cream paper, black ink outlines, blue and pink spot inks, yellow sticker accents, Bricolage Grotesque display, Newsreader narrative emphasis, Space Mono for data, 2.5px ink borders, and hard offset shadows. Use the shared suite header and shared token/style files. Keep halftones in margins, not behind text; keep controls, log rows, and data panels straight and scan-friendly. No glass, blur, gradients, or soft shadows.

The page tells a persuasive product story; its traffic sandbox is an operate-mode sample. Make the demo status visible where its values appear. Use text labels as well as color for HTML, JSON, and blocked outcomes. Keep buttons and inputs keyboard accessible, with visible focus and reduced-motion support. Preserve all source links and the existing story while avoiding claims that the prototype handles live traffic or enforces a real gate.
